# ESG & Financial Performance Analysis

Reproduces every table and figure in the ESG & Financials section of the
Verity site from three committed inputs.

## Run

```bash
python analysis/esg_financial_analysis.py \
    --esg docs/exports/verity_esg_scores_full.xlsx \
    --financials analysis/data/Data_20_10_2026.xlsx \
    --assets analysis/data/company_assets_liabilities_2020_2025_USD.xlsx \
    --out analysis/results/
```

## Inputs

1. `docs/exports/verity_esg_scores_full.xlsx` — the Verity ESG export
   (sheet "Scores by year"): one row per company-year with E, S, G, General
   and composite scores on a 0–100 scale, plus board size and firm ages.
   Generated by `backend/scripts/export_esg_scores.py`.
2. `analysis/data/Data_20_10_2026.xlsx` — the researcher's financial data
   (sheet "Ali Data"): market cap, EPS, leverage, net margin, RoE and RoA
   per company-year.
3. `analysis/data/company_assets_liabilities_2020_2025_USD.xlsx` — total
   assets and total liabilities in USD millions, one row per company-year.

The two financial inputs are committed into `analysis/data/` so the analysis
is reproducible from a clean checkout. The analysis script applies the four
researcher corrections (Saudi Aramco 2024/2025 RoA/RoE swaps, Sahara 2025
net margin, Bank Aljazira 2020 EPS) in-process before fitting any model.

## Outputs (in `--out`)

| File | Description |
|---|---|
| `ESG_vs_Financials_Results.xlsx` | All tables (descriptives, correlations, VIF, Spearman, regressions, Hausman, pillars, robustness, board, trends, corrections) |
| `esg_financials_results.json` | The same tables, consumed by the ESG & Financials page |
| `panel.pkl` | The cleaned analysis panel, for ad-hoc re-use |

## Dependencies

```bash
pip install -r analysis/requirements.txt
```
